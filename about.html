关于本站

一本随时翻阅的设计师案头索引：把散落在收藏夹里的设计类站点，整理成一份持续更新的分类目录。

这个导航是怎么来的

有一段时间我发现浏览器收藏夹里的网站越来越多，很难快速找到某个不常用的链接。于是就有了 WebStack 设计师网址导航：把散落在收藏夹里的设计类站点整理成一份分类索引，方便随时翻阅。

这里收录的都是平时用得比较多的站点，主要面向 UI 设计师、交互设计师、产品经理 与视觉创作者，涵盖界面灵感、图标字体、UI 资源、Mockup、摄影图库、在线工具与设计规范等方向，并且持续补充更新。

站内每条资源都按分类归档，从「常用推荐」开始浏览即可，也可以直接跳到任意一个分类；如果你也喜欢设计，希望这份索引能帮你省下一些翻找的时间。

按工作环节找资源

找灵感阶段：先看「界面灵感」「网页灵感」里的作品站与设计画廊，再翻「图形创意」「摄影图库」补充视觉参考。灵感枯竭的时候，这几类比漫无目的地搜索更快给出方向。

做素材阶段：「图标素材」「UI 资源」「Sketch 资源」「字体资源」「Mockup」覆盖了从图标、组件库到字体与样机的常见需求，多数资源可直接用于项目，使用前留意各站点自己的授权说明。

做交付阶段：「设计规范」与「在线工具」收录了主流设计系统文档、配色工具与切图工具，适合在整理标注、核对规范、交付开发时对照使用。

能力提升阶段：「视频教程」「设计文章」「设计电台」「UED 团队」收集了可以长期追更的学习渠道，比零散收藏更有体系。

适合谁使用

这份导航最初是给设计师自己用的，现在主要面向 UI 设计师、交互设计师、视觉设计师、产品经理、独立开发者，以及需要频繁查找设计素材的运营与市场同学。无论你是刚入行的新人，还是已经工作多年的从业者，都可以把它当作浏览器首页或书签栏的替代品。

需要说明的是，站内资源均来自公开渠道并指向第三方网站，版权与使用条款以各站点说明为准；导航本身只做整理与分类，不存储任何素材文件。

如果你有想推荐但还没被收录的站点，或者发现某个链接已经失效，欢迎通过 GitHub 仓库的 Issue 反馈，我会定期集中整理一次。
