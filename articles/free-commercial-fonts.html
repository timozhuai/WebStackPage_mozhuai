免费商用字体去哪找？一份可以直接照做的清单

字体是最容易踩版权坑的素材。这篇整理了开源中文字体、带授权筛选的英文字库站，以及下载前必须确认的三件事。

一个字体版权纠纷的赔偿金额，通常够买十套商业字体授权。更麻烦的是：很多设计师是在作品交付、甚至上线之后，才被告知字体不能商用。

问题不在于「哪里能下载字体」——那太容易了。问题在于下载站写着「免费」的字体，绝大多数只免费给个人使用。下面这份清单按「安全程度」从高到低排列，可以直接照着找。

一、开源中文字体：最不容易出错的一类

开源字体的授权写在明面上，通常采用 SIL Open Font License（OFL），允许商用、修改、再分发，只要不单独售卖字体本身就合规。

  • 思源黑体 / 思源宋体：Adobe 与 Google 联合开发，是国内商用场景里最常见的开源中文字体。在 Google Fonts 上以 Noto Sans SC / Noto Serif SC 的名字提供，字重齐全，覆盖简体、繁体与日韩字形。
  • 霞鹜文楷：基于开源字体改造的楷体，气质偏文艺，适合标题与书封。作者在 GitHub 上开源，采用 OFL 授权，更新频繁。
  • 厂商免费商用字体：阿里普惠体、HarmonyOS Sans、OPPO Sans 这类由公司发布的字体，通常允许免费商用，但授权条款写在各自的官网上，使用前务必去原页面确认，尤其是「是否允许嵌入 App/客户端」「是否允许用于商标」这两条。

拿到字体文件后，建议顺手把授权页面的截图和版本号一起存档。半年后回头找依据时，你会庆幸自己留了这一手。

二、带授权筛选功能的英文字库站

英文站点的坑和中文站不同：它们大多会明确标注授权，但需要你主动去看。

  • Google Fonts：全部字体开源，以 OFL 和 Apache 2.0 为主，页面上会直接显示授权类型。数量大、质量稳，缺点是风格偏「通用」，个性强的展示字体不多。
  • Fontshare：由印度字体公司 ITF 运营，整站字体免费，且明确允许个人与商业使用，是近两年质量上升最快的一家。
  • Fontsquirrel：老牌字库站，最大的价值是它提供授权筛选——可以只看「100% free」的字体，能省掉大量逐个查授权的时间。
  • DaFont / Lost Type 这类站点：字体数量惊人，但授权由上传的作者自己决定，同一个页面里可能既有完全免费商用的字体，也有仅供个人使用的字体。下载前必须点开每个字体自己的授权说明，不能只看站点标着「free」。

三、下载前必须确认的三件事

  1. 授权范围：个人使用、商业使用、嵌入软件、再分发，是四个独立的问题。很多免费字体只允许前两项。
  2. 字体文件自带的信息：正规字体在文件属性里会写授权说明，用字体管理器（macOS 的「字体册」、Windows 的字体设置，或 FontForge）都能看到，和官网说法对不上就存疑。
  3. 留存证据：把授权页面、下载日期、版本号一起存档。给别人交付时，也可以把授权说明一并附上，这本身就是专业度的一部分。

一个小习惯

建立一个自己的「可用字体库」：只把已经确认过授权的字体放进去，其余的一律不进设计稿。这个库开始会很薄，但每一款都可以放心用，长期来看比一个塞满来历不明字体的字体夹有用得多。
